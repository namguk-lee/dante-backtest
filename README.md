# Dante Backtest

한국 주식 시장에서 공개적으로 설명된 단테식 **EMA224 / 역배열 / 거래량 기준봉** 구조를 정량 검증하는 연구 저장소입니다.

## 현재 연구 규칙 (V3.1)
- 종가가 EMA224 상향 돌파
- 직전 80거래일 중 60일 이상 EMA224 아래
- EMA112 < EMA224 < EMA448
- 신호일 거래량 >= 20일 평균 거래량 × 1.5
- 양봉
- 동일 상장 에피소드 40거래일 신호 쿨다운
- 진입은 신호 다음 거래일 시가

## 손절 비교
- S1: EMA224 -2% 장중 이탈
- S2: EMA224 종가 이탈 후 다음 거래일 시가 청산
- S3: 기준봉 저가 이탈
- S4: 최근 20거래일 스윙 저점 이탈
- S5: ATR14 × 1.5

갭하락으로 손절가 아래에서 시작하면 **손절가가 아니라 실제 다음 시가로 체결**하도록 처리해 낙관적 편향을 줄였습니다.

## 전체 시장 검증 방식
GitHub Actions가 다음을 자동 수행합니다.

1. KOSPI/KOSDAQ 현재 상장 종목 수집
2. 연구기간 내 KRX 상장폐지 종목 수집
3. 동일 코드의 재상장/이전상장 왜곡을 줄이기 위해 상장 에피소드별 `series_id` 분리
4. 종목별 OHLCV 캐시
5. KOSPI/KOSDAQ 전체 신호 탐색
6. 5개 손절 방식 비교
7. TRAIN / VALID / TEST 분리
8. 거래대금 0 / 5억 / 10억 / 50억 민감도
9. 왕복비용 0 / 20 / 40bp 민감도

기본 구간:
- 데이터 워밍업: 2016-01-01부터
- 실제 신호 평가: 2018-01-01부터
- TRAIN: ~ 2021-12-31
- VALID: 2022-01-01 ~ 2024-12-31
- TEST: 2025-01-01 ~

## 실행
Actions → **Dante full-market backtest** → Run workflow

결과는 Actions artifact `dante-full-market-results-<run number>`에 저장됩니다.
