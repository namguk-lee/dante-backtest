# Dante Backtest

한국 주식 시장에서 공개적으로 설명된 단테식 **EMA224 / 역배열 / 거래량 기준봉** 구조를 정량 검증하는 연구 저장소입니다.

## 현재 연구 규칙 (V3.1)
- 종가가 EMA224 상향 돌파
- 직전 80거래일 중 60일 이상 EMA224 아래
- EMA112 < EMA224 < EMA448
- 신호일 거래량 >= 20일 평균 거래량 × 1.5
- 양봉
- 동일 상장 에피소드 40거래일 신호 쿨다운
- 진입은 신호 다음 거래일 시가

## 전체시장 데이터
현재 전체시장 워크플로의 1차 소스는 **FinanceData/marcap** 연도별 parquet입니다.

- 워밍업 데이터: 2016-01-01부터
- KOSPI/KOSDAQ의 당시 일별 구성종목을 그대로 사용
- 현재는 사라진 종목도 과거 행에 남으므로 현재 상장종목만 쓰는 생존편향을 줄임
- 코드 장기 공백/재사용을 고려해 listing episode별 `series_id` 분리
- raw 가격과 KRX 일간 등락률이 크게 불일치하는 기업행사 구간은 research-adjusted close로 연결
- 거래대금 0 / 5억 / 10억 / 50억 민감도 및 왕복비용 0 / 20 / 40bp 비교

## 손절 비교
- S1: EMA224 -2% 장중 이탈
- S2: EMA224 종가 이탈 후 다음 거래일 시가 청산
- S3: 기준봉 저가 이탈
- S4: 최근 20거래일 스윙 저점 이탈
- S5: ATR14 × 1.5

갭하락으로 손절가 아래에서 시작하면 **손절가가 아니라 실제 시가로 체결**하도록 처리해 낙관적 편향을 줄였습니다.

## 검증 구간
- 실제 신호 평가: 2018-01-01부터
- TRAIN: ~ 2021-12-31
- VALID: 2022-01-01 ~ 2024-12-31
- TEST: 2025-01-01 ~

## 첫 전체시장 실행 — Run #8
GitHub Actions run #8에서 전체 파이프라인이 성공했습니다.

- 입력 패널: 6,121,604행
- listing episode: 3,557개
- 역사상 존재했지만 종료시점에는 사라진 episode: 954개
- A 기본신호: 11,927건
- TEST(2025~2026) 신호: 2,547건

TEST 기본신호의 60거래일 미래수익은 평균 약 -0.15%, 중앙값 약 -5.27%, 양(+)의 수익 비율 약 38.4%였습니다.
따라서 **현재 A 규칙만으로는 최근 구간에서 독립적인 매수전략으로 채택하지 않습니다.**

5개 손절 중 TEST 평균손익이 가장 덜 나빴던 것은 S4(최근 20일 저점)였지만 평균 약 -0.59%로 여전히 음수였습니다.
이는 손절 최적화보다 **진입 품질/시장상태 필터 개선이 우선**임을 의미합니다.

탐색적 후속 진단에서는 다음 방향이 일관되게 개선 후보로 나타났습니다.
- 다음날 시가가 EMA224 대비 +5%를 넘으면 추격 회피
- EMA112↔EMA224 이격이 +5% 이내인 수렴형 우선
- 거래량 20일 평균 10배 이상 과열형 회피
- KOSPI와 KOSDAQ 분리 검증

이 후속 조건은 이미 TEST 결과를 본 뒤 도출했으므로 **새로운 독립 OOS 결과로 간주하지 않습니다.** 다음 버전에서는 walk-forward/연도별 안정성으로 재검증합니다.

## 실행
Actions → **Dante full-market backtest** → Run workflow

결과는 Actions artifact `dante-full-market-results-<run number>`에 저장됩니다.
