**범위:** 기존 전종목 공구리 A와 연구용 B/C 구분을 유지한다. 정규 main 스캐너·실행 중인 자동화·실제 주식 주문은 수정하지 않는다.

선정된 2026-11-09~13의 동일 주간 기준 실제 연구 스캐너 GitHub Actions 세 차례 성공:

- [검색 후보 선별 최적화 Run 2](https://github.com/namguk-lee/dante-backtest/actions/runs/43465076979)
- [차트 BB20-shift26/한글 글꼴 보강 Run 3](https://github.com/namguk-lee/dante-backtest/actions/runs/43466020759)

각 ZIP의 `week_research_events.csv`에 대해 키=(신호일, 6자리 코드, 연구모델) 비교:

Run1만 발생: 2026-11-11 아스플로(159010) SMA5 연구 턴.
Run2/3만 발생: 2026-11-13 하나금융지주(086790) SMA5 연구 턴.

Run1->Run2/3에서 **한 개씩 자리바뀜**. 공통된 146개는 검토한 당일 가격, 상대거래량, EMA224 이격, ATR14이 같았다. Run2 vs Run3은 이 항목 및 147개 키 모두 동일하였다.

**원인은 아직 확정되지 않음.** 매 실행 시 marcap 최신 연도를 새로 수신하고 Naver로 최근 가격을 보강하므로, 외부 가격 수정 가능성, 리서치 기업행사 조정 계산, 스캐너의 후보 선별 방식 변화 등을 구별해야 한다. 소스 패널 데이터 SHA·조정계수·원시 종목별 OHLCV를 아티팩트로 함께 저장해 원인을 좁히기 전에는 완전 재현성을 주장하지 않는다.

**1단계 잠정 통과:** 최신 두 구현의 신호 날짜/종목/패턴 키 및 주요 기록값은 일치. 원시 데이터 불변성까지는 아직 미통과.

## Stage 2 — 표준 수학 정확성

EMA(초기화 포함), SMA, ATR14(Wilder), BB(n,2), Parabolic SAR, 일봉 Anchored VWAP의 산식·기준 봉·조정가/원가격 통일 여부를 단위 테스트와 외부 검산으로 비교한다. Pine v6는 실제 TradingView 컴파일·차트 확인 전까지 **미검증** 표시.

## Stage 3 — 공개 지표 원본 사례 대응

공식 출처/권한 있는 차트의 발생일과 미발생일을 모아 독립 모델별 일치율/오탐률/가격선 오차를 **종목·기간 홀드아웃**으로 측정한다. 공식 유료 원본의 정확한 수치/출력 라벨이 없으면 복제 성공률을 계산할 수 없다.

## Stage 4 — 독립 성능 검증 및 PDF 운영

지표별 발생 신호 수와 누락·중복, 시장 구간별 성과·중앙값·MAE·MFE, 비용·체결 방식, 가격 기준일·데이터 원본 해시를 표기. 연구용 B/C는 기존 A 추천과 별도 PDF 페이지에 수록하며 미검증 종목은 연구 후보로만 표기. 20일 단순 보유와 구조 손절/2R의 결과를 직접 대등 비교하지 않는다. 성공적으로 검증된 지표만 최종 연구 페이지에 표시하고 main의 거래/추천 로직을 함부로 바꾸지 않는다.
