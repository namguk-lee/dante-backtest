# Dante formula research — public evidence matrix

Status: research-only. Do **not** treat proprietary indicators as reproduced formulas.

Last research pass: 2026-09-29

## Evidence levels

- **A — Publicly stated**: Dante/official channel explicitly describes the rule.
- **B — Repeated official examples**: repeated in official public recap posts, but exact formula is not disclosed.
- **C — Third-party approximation**: external recreation; useful only as a hypothesis.
- **D — Unknown**: insufficient public evidence.

## 1. Price moving averages — A

Official chart setup uses exponential moving averages:
- EMA 5 / 15 / 33 / 56 / 112 / 224 / 448
- 112 ≈ 6-month line, 224 ≈ 1-year line, 448 ≈ 2-year line.

Source:
- https://contents.premium.naver.com/jusikdante/jusikdante1/contents/240903191444551ao

## 2. 256 technique — A

Public rule:
- Basic 256 = 5 / 20 / 60.
- Price recovers 20, 5 crosses above 20, while 60 remains overhead.
- It is described as a pre-trend-reversal location.
- Medium/long-horizon adaptation explicitly changes the three lines to **5 / 112 / 224**.

Implication for our research:
- A falling or overhead 224 is **not automatically invalid** for a 5/112/224 256 setup.
- This pattern must be detected separately from Bowl-3 completion.

Source:
- https://contents.premium.naver.com/jusikdante/jusikdante1/contents/250423172747615pl

## 3. MA-hit / 이평때리기 — A

Public rule:
- Large decline causes long MAs to spread.
- Reclaim/settle above 112 -> challenge 224.
- Reclaim/settle above 224 -> challenge 448.
- Public material calls this an expanded reverse-MA situation.

Implication:
- Large MA gap and still-declining longer MA can be normal at the **early** stage.
- Do not force EMA224 positive slope as a universal Dante requirement.

Sources:
- https://contents.premium.naver.com/jusikdante/jusikdante1/contents/250401154145712bd
- https://contents.premium.naver.com/jusikdante/jusikdante1/contents/250826145243406jo

## 4. Bowl pattern / 밥그릇 — A

Public structure:
- 1 = decline
- 2 = long base/sideways accumulation
- 3 = 224 recovery/breakout area
- 4 = expansion/uptrend
- A repeated public rule is that Bowl-2 duration should be longer than Bowl-1 duration.

This is a **separate technique**, not a universal prerequisite for all Dante setups.

## 5. Share / 지분 technique — A for concept, D for exact 1:1 geometry

Public concept:
- Above a chosen long MA = buy-side territory.
- Below = sell-side territory.
- Flow shifts as price changes from sell-side to buy-side territory.
- Practical public recaps use 60 / 112 / 224 as selectable reference MAs.
- Public recaps repeatedly say a move of **1:1 or more** around the selected MA has higher credibility.

Examples:
- CP System: 60MA-based 1:1, then 112 settlement; targets 224 / 448.
- Messe Esang: 224MA-based 1:1 and support.
- BCNC: 112MA-based 1:1 developing.

What is **not** publicly confirmed:
- The exact geometry of 1:1: mirrored price distance, swing amplitude, time symmetry, or another construction.

## 7. Anchor / 기준봉 — A for concept, D for fixed numeric threshold

Public concept:
- appears after long decline or sideways action
- a central/strong bullish candle that overcomes selling pressure
- stronger credibility with large volume
- failure occurs when the anchor is decisively broken
- public examples often use the anchor open as a risk reference

Not publicly established as a universal formula:
- +5% return
- 2.0x volume
- +3.5% body

Those values in earlier scanners were **our research proxies**, not Dante's published constants.

Source:
- https://contents.premium.naver.com/jusikdante/jusikdante1/contents/251002161729128jt

## 15. Share / 지분 1:1 empirical narrowing — 2026-09-29

Public wording and dated-case reconstruction now narrow the practical interpretation:

- official/public descriptions repeatedly say an MA-relative **1:1 or more** position, not “exactly 1.00”
- a public transcript describes the structure as recovering by roughly the amount previously fallen
- the reference line can change (20 / 60 / 112 / 224 are all discussed publicly)
- the reference MA is therefore part of the technique; the same stock can have a different target depending on the chosen MA

Dated confirmed examples used:
- Messe Esang: EMA224, 2025-06-17
- CP System: EMA60, 2025-08-01
- BCNC: EMA112, 2025-08-08
- Saevitchem: EMA112, 2025-08-01
- Parton: EMA112, 2025-11-17

A research candidate that compares the current buy-side recovery above the selected MA against the preceding sell-side downside around the structural recovery cross produced:

- Messe Esang: 2.53
- CP System: 1.67
- BCNC: 2.99
- Saevitchem: 1.01
- Parton: 1.64

All 5 publicly labeled “1:1 or more” examples were >= 1.

A public pre-confirmation control:
- NanoEntek, EMA224, 2025-05-29: -0.60 (price had not established the required buy-side recovery)

However, **this candidate has weak standalone selectivity**. Same-date full-market controls showed that among stocks already above the selected MA and with a computable recovery structure, the candidate was >=1 in roughly 60%–89% of the eligible universe depending on date/reference MA.

Therefore:

1. The amplitude interpretation is currently the strongest working approximation for the **meaning of 1:1**.
2. It must **not** be used alone as a recommendation filter.
3. It should be combined with the context repeatedly shown in official examples: reverse-array/turning structure, MA settlement, accumulation, concrete/support, and other confirmation signals.
4. The exact proprietary/manual swing-selection rule remains unconfirmed; name the implementation `research_share_1to1_amplitude_proxy`, not “exact Dante formula”.

Fixed-window candle-count 50:50 and simple fixed-window area ratios were not consistent enough across the five confirmed cases to treat as the formula.

## 16. Public Bowl duration condition — historical diagnostic (2026-09-30)

The public rule “Bowl-2 should be longer than Bowl-1” was tested as **diagnostic context**, not fitted as a new entry threshold.

Transparent translation reused the existing `bowl_mask` geometry:
- within the latest 220 sessions, locate the trough,
- locate the preceding peak within up to 160 sessions,
- Bowl-1 proxy = peak -> trough duration,
- Bowl-2 proxy = trough -> signal duration,
- public duration context = Bowl-2 >= Bowl-1, with the existing shape guards (decline >=10 sessions, decline <= -20%, base >=40 sessions).

Workflow:
- Dante event-first backtest Run #19
- commit: `eb4877973b0ce0fdaa361dcdcc4de7cc9f5e3011`

Result:
- TRAIN: the public duration context separated stronger E3/E4 groups.
- VALID: some **mean** 20-day returns improved, but medians and win rates remained weak/negative, indicating winner concentration.
- TEST: the public duration context was worse in the very small qualifying samples; for example E4_REACCEL_3D had n=2 and -10.40% mean 20-day return versus +9.98% for the non-matching group (n=11).

Conclusion:
1. Keep “Bowl-2 >= Bowl-1” as a faithful public **structure descriptor**.
2. Do **not** use the current mechanical translation as a standalone ranking/entry filter.
3. The public concept may still be visually/manual and broader than this trough/peak proxy.
4. Continue testing other explicitly public confirmations before changing the live recommendation rule, especially the 112/224 reverse-to-positive transition.
