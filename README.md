# Dante Backtest

한국 주식 시장에서 공개적으로 설명된 단테식 EMA224 / 역배열 / 거래량 기준봉 구조를 정량 검증하는 연구 저장소입니다.

## 현재 연구 규칙 (V3)
- 종가가 EMA224 상향 돌파
- 직전 80거래일 중 60일 이상 EMA224 아래
- EMA112 < EMA224 < EMA448
- 신호일 거래량 >= 20일 평균 거래량 x 1.5
- 양봉
- 동일 종목 40거래일 신호 쿨다운

## 손절 비교
- S1: EMA224 -2% 장중 이탈
- S2: EMA224 종가 이탈 후 다음 거래일 시가 청산
- S3: 기준봉 저가 이탈
- S4: 최근 20거래일 스윙 저점 이탈
- S5: ATR14 x 1.5

## 전체 시장 검증
`.github/workflows/dante-full-market.yml`을 수동 실행하면 KOSPI/KOSDAQ + 연구기간 내 상장폐지 종목의 OHLCV를 수집하고 전체시장 백테스트를 실행합니다.
